# Заметки и карта

Заметки хранятся в Redux (`notes`), а список доступных мест — в `mapLocations`. Общие места задаются в `map/model/location.ts`, пользовательские загружаются из прежнего ключа `dnd-map-user-locations`. Формат и ключ существующего хранилища меток не менялись.

Поле заметки `locationId` содержит постоянный ID места или `null`. Старые заметки без этого поля остаются доступными. Переименование или перенос места не меняют связь. При удалении метки заметки и ссылка на её ID сохраняются: их можно найти фильтром по недоступному месту, перепривязать или отвязать через редактор.

Переходы:

- `/map?place=<id>` — выбрать место и приблизить карту после загрузки изображения.
- `/notes?place=<id>` — показать записи выбранного места.
- `/notes?place=<id>&new=1` — открыть новую заметку с уже выбранным местом.
- `/notes?place=<id>&note=<noteId>` — показать и выделить конкретную заметку.

Сохранение заметок и меток остаётся локальным для браузера. Серверной синхронизации нет.

На планшетах в альбомной ориентации (от 768 px) карта и список мест стоят рядом. В портретной ориентации до 1100 px список открывается панелью, на телефоне — снизу. На больших экранах панель всегда справа. Полноэкранный режим сохраняет эту раскладку.
