# Данные персонажей

Здесь хранятся оригинальные JSON-экспорты Long Story Short. Не нужно вручную разбирать или переписывать строку `data` внутри файла.

Чтобы добавить героя:

1. Добавьте экспорт отдельным JSON-файлом в эту папку.
2. Импортируйте файл в `../model/charactersSlice.ts`.
3. Добавьте `importLssCharacter(экспорт, 'стабильный-id')` в массив `characters`.

Чтобы обновить героя, замените его JSON и сохраните прежний ID. После новой сборки и публикации данные обновятся у всех пользователей. Redux загружается из этих файлов при открытии приложения; редактирования листов и синхронизации текущих хитов между пользователями нет.

Адаптер поддерживает характеристики, сохранённые боевые показатели, владения и экспертизу навыков, половину бонуса владения барда, числовой `customModifier`, спасброски, оружие и текстовые разделы. Он не исполняет произвольные формулы из `bonuses`. Боевые показатели берутся из `vitality` без перерасчёта. Заклинания по внешним ID, личные заметки и история пока не отображаются. Портрет загружается по ссылке из экспорта; при ошибке показываются инициалы.

Сетка: телефон до 639 px — одна колонка, планшет 640–1199 px — две, десктоп от 1200 px — три. Общее меню сворачивается на экранах уже 1024 px.
