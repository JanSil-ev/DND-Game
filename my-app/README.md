# D&D Campaign

React, TypeScript, Vite, React Router, and SCSS project scaffold for a D&D campaign app.

## Development

```bash
npm install
npm run dev
```

`npm run build` checks TypeScript before creating a production build. Use `npm run lint` to check the source files.

## Structure

- `src/app` contains routing, providers, the main layout, and global styles.
- `src/pages` contains route-level pages.
- `src/modules` contains D&D domain modules.
- `src/features` contains user-action feature areas.
- `src/shared` contains shared UI, assets, and utilities.
